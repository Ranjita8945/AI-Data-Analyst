# 📊 AI Data Analyst

### An Interactive Data Analysis Application Built with Python

AI Data Analyst is an interactive web application designed to simplify data analysis by automating data cleaning, exploring datasets, and performing SQL-based analytics.

The application allows users to upload datasets and explore meaningful insights through an easy-to-use interface.

## 🚀 Features

- 📁 **Dataset Upload:** Upload CSV datasets for analysis.
- 🧹 **Automated Data Cleaning:** Handle missing values and prepare datasets for analysis.
- 📊 **Exploratory Data Analysis:** Understand dataset structure, distributions, and patterns.
- 🗄️ **SQL Analytics:** Perform SQL-based queries and analyze structured data.
- 📈 **Data Visualization:** Generate visual insights from uploaded datasets.
- ⚡ **Interactive Dashboard:** Explore data through a Streamlit interface.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project directory

```bash
cd AI-data-analyst
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the environment

Windows:

```bash
.venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
streamlit run app.py
```
